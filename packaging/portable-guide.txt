Private Note Desktop Portable

使用方式
1. 将整个压缩包解压到可写目录，例如桌面、D 盘工作目录或个人文档目录。
2. 进入 `PrivateNoteDesktop` 文件夹，双击 `PrivateNoteDesktop.exe` 启动客户端。
3. 首次启动会先进入登录页；如果本地还没有账号，需要先创建管理员账号。
4. 登录成功后，点击右上角齿轮，进入设置页。
5. 在“账号管理”里可继续创建成员账号或删除其他账号。
6. 在“环境诊断 / 依赖管理”里按需安装项目私有 Ollama。
7. 安装完成后，再在客户端内安装推荐模型。

说明
- 本便携版已经包含 Python 运行时和项目普通依赖，无需额外安装 Python 或执行 `uv sync`。
- 登录账号后，后续保存笔记会自动记录最后修改署名。
- CPU 运行时会随发布包提供；GPU 运行时、GPU 加速库与模型不会预置在压缩包中，而是在客户端“依赖管理终端”里按需安装到项目目录。
- 请不要把便携版直接放到 `Program Files` 这类受限目录运行，否则项目私有数据与模型可能无法写入。
